# ESP32-S3 YouTube AntiDPI Proxy

Высокопроизводительный и легковесный прокси-сервер на базе **ESP32-S3 (N16R8)** для обхода DPI-блокировок YouTube и сервисов Google в домашней сети. Проект работает как HTTP/HTTPS CONNECT прокси с поддержкой умной фрагментации TLS `ClientHello`, кэшированием стратегий в NVS и встроенной веб-панелью мониторинга.

---

## 🚀 Основные возможности

* **Обход DPI (Deep Packet Inspection):** Поддержка продвинутых стратегий фрагментации TLS ClientHello (`S1–S4`, включая `TLSRECx3+Split` и `Disorder`), позволяющих успешно обходить ТСПУ.
* **Автоматическое обучение и кэширование:** Прокси автоматически подбирает и проверяет рабочие стратегии для каждого домена Google/YouTube, сохраняя результаты в NVS (энергонезависимую память).
* **Веб-панель мониторинга:** Удобный дашборд в реальном времени отображает загрузку слотов, статус SRAM/PSRAM, текущие задержки (EMA TTFB) и позволяет настраивать стратегии «на лету».
* **PAC-скрипт:** Автоматическая генерация файла `proxy.pac` для бесшовной маршрутизации трафика только заблокированных ресурсов через плату.
* **Оптимизация памяти:** Эффективное использование 8 МБ PSRAM для пулов буферов и изоляция сетевых задач через FreeRTOS.

---

## 🛠 Требования для сборки

* **Аппаратное обеспечение:** Плата ESP32-S3 с поддержкой PSRAM (рекомендуется ESP32-S3-DevKitC-1 с 16 МБ Flash и 8 МБ PSRAM).
* **ПО:** [VS Code](https://code.visualstudio.com/) с установленным расширением **PlatformIO**.

## 📦 Пошаговый гайд по установке и подключению

### Шаг 1. Подготовка файлов проекта
1. У вас в репозитории уже есть файл `src/main.cpp`.
2. В папке `src/` создайте файл конфигурации сети **`secrets.h`**:
   ```cpp
   #pragma once

   #define SECRET_WIFI_SSID     "Имя_Вашего_Wi-Fi_Роутера"
   #define SECRET_WIFI_PASSWORD "Пароль_От_Wi-Fi"
Шаг 2. Сборка и прошивка платы
Откройте папку проекта в VS Code с расширением PlatformIO.

Подключите плату ESP32-S3 к компьютеру по USB-кабелю.

Нажмите кнопку Upload (стрелочка в нижней панели PlatformIO) для компиляции и прошивки микроконтроллера.

После завершения прошивки откройте монитор порта (Monitor, скорость 115200), чтобы убедиться, что плата успешно подключилась к вашему Wi-Fi и получила локальный IP-адрес (например, 192.168.31.150).

Шаг 3. Подключение клиентских устройств (ПК и смартфоны)
Устройства в вашей домашней сети могут использовать прокси двумя способами: через автоматический PAC-скрипт (рекомендуется) или ручной настройкой.

Способ А. Использование PAC-файла (Автоматически)
В настройках сети вашего устройства (или браузера) укажите путь к автонастройке прокси:http://192.168.31.150:8080/proxy.pac

Все запросы к YouTube и видеосерверам Google пойдут через плату, а остальные сайты — напрямую через ваш роутер.

Способ Б. Ручная настройка HTTP/HTTPS Прокси
Зайдите в настройки сети устройства и включите ручной прокси-сервер:

Адрес (Host / IP): 192.168.31.150 (или IP, который выдал вашей плате роутер).

Порт (Port): 8080

Прокси работает в режиме HTTP/HTTPS CONNECT, поэтому поддерживает шифрованный трафик напрямую.

Шаг 4. Веб-панель управления
Вы можете в любой момент изменить настройки стратегии обхода DPI или посмотреть детальный живой лог работы.

Откройте браузер на любом устройстве в вашей сети.

Перейдите по адресу: http://192.168.31.150:8080/

На панели вы увидите:

Свободную память SRAM и PSRAM.

Количество активных сетевых слотов.

Кнопки принудительного переключения стратегий (S0–S4) и кнопку сохранения кэша в NVS.

Живой лог соединений (Live Log).
